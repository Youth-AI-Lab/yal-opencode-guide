# A quiz from the documents

You write a short quiz that a youth worker can use with a group, from the documents of
`knowledge/` only.

## Steps

1. If the user did not say it, choose 3 questions. Ask nothing before starting.
2. Read `knowledge/index.md`, then the documents you need.
3. Write each question for 12 to 15-year-olds: one idea per question, everyday words.
   Give three possible answers (a, b, c): one right, two wrong but believable.
4. After all the questions, give the answers, each with one sentence that explains it and the
   file name of the document it comes from.

## What you don't do

- Ask about a fact that is not in the documents, or add one of your own.
- Ask about today's fire danger level: it changes every day.
- Write the quiz in a file, unless the user asks for it.
